      Where bipartite graphs show up
      
    
      
      
      
        
      Test it: can the conflicts be split into two groups?
      
        
        
          
      • LeetCodeIs Graph Bipartite (LC 785) and Possible Bipartition (LC 886): people who dislike each other go to different groups.
        • 
          
      • SchedulingTwo exam slots: two exams that share a student can't share a slot. Two slots work exactly when the conflict graph is bipartite.
        • 
          
      • EDADouble-patterning lithography: shapes too close together must go on different masks. An odd cycle is a conflict no mask split can fix, so the layout changes or a stitch splits a shape across both masks.
        • 
          
      • ParityGrids and trees are always bipartite (team = (row + col) mod 2, or depth mod 2). That's the chessboard argument: a knight always lands on the other color.
        • 
        
      
      
      
      
      
        
      Built bipartite: two kinds of nodes, edges only between kinds
      
        
        
          
      • MatchingJobs ↔ machines, interns ↔ teams: maximum matching (Hopcroft–Karp) and min-cost assignment (Hungarian). In a bipartite graph, max matching = min vertex cover (König).
        • 
          
      • EDAA netlist is a cells ↔ nets incidence graph, the form partitioners and placers work on. Pin and I/O assignment is a bipartite matching.
        • 
          
      • BackendUsers ↔ hotels (bookings, reviews) for recommendations, and every many-to-many table (students ↔ courses) is a bipartite graph.
        • 
        
      
      
      
    
      
    
      Two colors take O(V + E) with one BFS. Three colors is NP-complete. That gap is why "is it bipartite?" is the special, fast case worth recognizing.
      
  
      

  
      
    
      The model in five sentences
      
    
        
      
      1. Every edge says "different teams". So paint the start team A and alternate.
        2. 
      
      2. BFS paints in layers: a node's team is its layer number mod 2.
        3. 
      
      3. A BFS edge joins the same layer or two neighboring layers. Neighboring layers are always opposite teams, so those edges are fine.
        4. 
      
      4. An edge inside one layer joins two same-team nodes. With the two BFS paths back to their common ancestor it forms a cycle of length 2k + 1: odd. So no odd cycle ⇔ bipartite.
        5. 
      
      5. Each component needs its own start: that's the outer loop. Without it, an odd cycle in another component is never seen.
        6. 
    
      
    
      → or Space step · ← back. Each node is queued once and each edge is checked from both ends, so the whole run is O(V + E).
