        The model in four sentences
        
    
          
      
        1. A DFS is a flood: from any node it fills that node's neighborhood (its SCC), then runs downhill into every neighborhood below.
          2. 
      
        2. A node finishes only after everything it reaches is done, so an upstream neighborhood always finishes after a downstream one. The last finisher is at the top.
          3. 
      
        3. Flipping every edge keeps each neighborhood the same, but turns the top into the bottom.
          4. 
      
        4. So pass 2 floods the flipped graph from the latest finisher first. It starts at the bottom, can't leak, and every edge out of it hits a wall: a neighborhood that's already labeled.
          5. 
    
        
    
        → or Space step · ← back. Each node and edge is touched a constant number of times in each pass, so the whole thing is O(V + E).
